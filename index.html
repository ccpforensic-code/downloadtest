檔案下載速度測試

點擊個別檔案開始下載及測速。每次請求都會加入隨機參數， 並要求瀏覽器不要使用 HTTP 快取。 測速完成後可自行選擇是否儲存檔案。 測速紀錄只會先儲存在此瀏覽器， 必須按下「上傳紀錄」才會上傳至 Server。

🔒 連接內聯網伺服器

iOS Safari 對內聯網域名（如 923test.local）有額外的私隱保護。 請嘗試以下方法之一來建立連接：

方法 1： 輸入內聯網伺服器 IP 地址
💡 提示：在內聯網中，請用 IP 地址（如 192.168.x.x）代替域名
方法 2： 點擊下方按鈕觸發連接
⏳ 尚未連接。請嘗試以上方法。
